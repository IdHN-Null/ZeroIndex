# Welcome!

This is the Journal section of the **ZeroIndex** learning platform.

## Key Features
- **Multilingual Support**: Content is provided in various languages including Korean and English.
- **Category System**: Articles are organized based on folder structure.
- **Custom Configuration**: You can freely customize category colors, titles, etc. via `_config.json`.
